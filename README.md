## Development

```bash
git clone https://github.com/aguadossj/frieren.git && cd frieren
cd app && npm install && npm run dev   # también en el móvil: http://<ip-del-portátil>:5173
npx vercel login                        # una vez, para poder desplegar
```

Abre Claude Code en la raíz del repo (no en `app/`). Lee [PLAYBOOK.md](PLAYBOOK.md) para roles,
timeline y comandos (`/kickoff`, `/checkpoint`, `/ship`, `/setup-report`). Las reglas para los
agentes están en [CLAUDE.md](CLAUDE.md).
